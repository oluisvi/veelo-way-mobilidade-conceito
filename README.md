# Conceito Veelo Way

Protótipo estático e responsivo de pré-venda para mobilidade elétrica.

## Abrir

Abra `index.html` em um navegador. Não precisa instalar dependências nem iniciar servidor.

## Explorar

- Alterne as três direções visuais no topo.
- Use busca e categorias no catálogo.
- Os CTAs abrem WhatsApp com texto preenchido para revisão manual, sem enviar automaticamente.

## Conteúdo

Os produtos são arquétipos ilustrativos. Nenhum modelo, preço, autonomia, estoque, região atendida ou serviço foi confirmado. Consulte [BRIEF_DO_PROJETO.md](BRIEF_DO_PROJETO.md) para os fatos, hipóteses e validações pendentes; [MENSAGEM_PROPOSTA.md](MENSAGEM_PROPOSTA.md) contém uma mensagem de apresentação.

Fotos são imagens de referência hospedadas no Unsplash e dependem de conexão com a internet. O número inserido no link WhatsApp foi listado no relatório, mas não foi verificado independentemente.
